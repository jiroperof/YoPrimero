1. RESUMEN EJECUTIVO Y PROPÓSITO
================================================================================
YoPrimero es una aplicación nativa Android diseñada para conductores de apps de
viaje y repartidores de delivery (Yummy Rides, Yango, Ridery, Uber, DiDi, PedidosYa).

La aplicación NO interactúa con las APIs internas de esas empresas. En su lugar,
optimiza el entorno del sistema operativo Android para:
  1. Reducir la latencia de red (Ping) forzando consultas DNS a Cloudflare 1.1.1.1.
  2. Bloquear redes sociales y descargas en segundo plano (Facebook, Instagram, TikTok)
     mediante un Firewall VPN local para reservar el 100% del ancho de banda.
  3. Evitar que el sistema operativo o ahorradores de batería de marcas chinas
     (Xiaomi/HyperOS, Infinix/XOS, Samsung) maten las apps de trabajo.
  4. Mantener el módem GPS en alta precisión (2s) y la antena 4G/LTE activa (RRC Connected).
  5. Elevar al 100% el volumen y encender la pantalla cuando llegan ofertas de viaje.

2. ARQUITECTURA GENERAL DEL PROYECTO
================================================================================
Patrón: UI (Jetpack Compose) -> ViewModel (AndroidViewModel) -> Repositorios -> Servicios

Stack Tecnológico:
  - Lenguaje: Kotlin 2.1.10
  - UI: Jetpack Compose con Material 3 y esquema forzado Neo-Dark Driver
  - Arquitectura: MVVM (Model-View-ViewModel) con StateFlow reactivo
  - Inyección de Dependencias: Hilt (@HiltAndroidApp, @AndroidEntryPoint, @HiltViewModel)
  - Asincronía: Coroutines (Dispatchers.IO) + StateFlow + Java Executor Threads
  - Navegación: Jetpack Navigation Compose (AppNavHost)

3. MÓDULOS CORE
================================================================================

-------------------------------------------------------------------------------
3.1 NETWORK FIREWALL & MOTOR PROXY (FirewallVpnService.kt & ProxyWorker.kt)
-------------------------------------------------------------------------------
  - Extiende VpnService y crea la interfaz TUN virtual (tun0) en el kernel.
  - VpnService.Builder configura DNS de baja latencia Anycast de Cloudflare:
    addDnsServer("1.1.1.1") y addDnsServer("1.0.0.1").
  - FIREWALL POR APP: Usa builder.addAllowedApplication(...) para cada paquete
    de la lista blanca dinámica (Yummy Rides, Yango, Ridery, Play Services, Chrome).
  - MOTOR PROXY TUN2SOCKS (ProxyWorker.kt):
    * UDP (DNS 53) y TCP (SYN, SYN-ACK, ACK, PSH, FIN, RST) mediante SocketChannel.
    * TCP Keep-Alive (keepAlive = true, tcpNoDelay = true) para conexiones WebSocket wss://.
  - Ciclo de Vida Limpio:
    * Override onRevoke(): Cierra el túnel si el sistema cancela la VPN.
    * stopInternal(): Cierra el ParcelFileDescriptor (fd.close()), detiene hilos y
      retiene la notificación con stopForeground(STOP_FOREGROUND_REMOVE).

-------------------------------------------------------------------------------
3.2 AUTO-CONFIGURACIÓN DE BATERÍA (AutoConfigAccessibilityService.kt)
-------------------------------------------------------------------------------
  - Navega por ACTION_IGNORE_BATTERY_OPTIMIZATION_SETTINGS para eximir a las apps.
  - Filtro de Seguridad de Paquete: Solo procesa eventos en Ajustes o Seguridad del sistema.

-------------------------------------------------------------------------------
3.3 HUD FLOTANTE & WAKELOCK (HudOverlayService.kt & WakeLockHelper)
-------------------------------------------------------------------------------
  - Ventana flotante (TYPE_APPLICATION_OVERLAY) arrastrable.
  - Niveles de estado: "Excelente 🟢", "Bueno 🟡", "Lento 🔴", "Buscando red...".
  - PartialWakeLock de seguridad con límite de 10 horas.

-------------------------------------------------------------------------------
3.4 LIMPIADOR DE RAM (util/RamCleaner.kt)
-------------------------------------------------------------------------------
  - Mata procesos en segundo plano respetando servicios de sistema y ubicación.

4. MÓDULOS DE ASIGNACIÓN AVANZADA
================================================================================

-------------------------------------------------------------------------------
4.1 REFRESCO GPS DE ALTA PRECISIÓ N (LocationRefreshService.kt)
-------------------------------------------------------------------------------
  - Usa FusedLocationProviderClient con Priority.PRIORITY_HIGH_ACCURACY.
  - Solicita coordenadas cada 2000 ms (2s) mientras el Modo Trabajo está activo.
  - Evita que el hardware GPS entre en suspensión para reportar ubicación exacta a Yummy/Yango.

-------------------------------------------------------------------------------
4.2 PREVENCIÓN RRC IDLE / ANTENA 4G (ProxyWorker.kt)
-------------------------------------------------------------------------------
  - Envía paquetes UDP nulos de 1 byte a 8.8.8.8:53 cada 3 segundos.
  - Mantiene la radio celular en estado RRC Connected, eliminando la latencia de reconexión.

-------------------------------------------------------------------------------
4.3 SOBREESCRITURA DE ALERTAS (AlertOverrideNotificationService.kt)
-------------------------------------------------------------------------------
  - Extiende NotificationListenerService.
  - Al detectar notificaciones de Yummy, Yango o Ridery:
      1. Adquiere WakeLock para encender la pantalla (SCREEN_BRIGHT_WAKE_LOCK + ACQUIRE_CAUSES_WAKEUP).
      2. Eleva STREAM_MUSIC al 100% de volumen.
      3. Emite un tono sonoro de alerta de alta frecuencia con ToneGenerator.
